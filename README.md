# 🚀 Spaceship Titanic - Kaggle Competition  

![Spaceship Titanic](https://storage.googleapis.com/kaggle-competitions/kaggle/31265/logos/header.png)  

## 📖 Overview  
This repository contains my solution for the **Kaggle Spaceship Titanic Competition**. The objective was to predict whether passengers aboard the fictional Spaceship Titanic were transported to another dimension. I developed and trained a Deep Neural Network (DNN) using TensorFlow to achieve this goal.  

## ✨ Features  
- **Data Preprocessing:**  
  - Handled missing data using imputation techniques.  
  - Performed feature engineering to create new, meaningful features for the model.  
- **Exploratory Data Analysis (EDA):**  
  - Visualized key patterns and correlations in the dataset.  
  - Extracted insights that informed model design and preprocessing strategies.  
- **Deep Learning Model Development:**  
  - Designed and trained a TensorFlow-based Deep Neural Network (DNN).  
  - Optimized the architecture by experimenting with:  
    - Number of layers and neurons  
    - Activation functions  
    - Dropout for regularization  
  - Used early stopping and learning rate scheduling to enhance model performance.  
- **Model Evaluation:**  
  - Evaluated model performance using metrics such as accuracy and precision.  
  - Analyzed training and validation losses to ensure robust generalization.  

## 🛠️ Tools & Technologies  
- **Programming Language:** Python 🐍  
- **Libraries & Frameworks:**  
  - TensorFlow  
  - Pandas  
  - NumPy  
  - Matplotlib, Seaborn  
- **Development Environment:** Jupyter Notebooks  

## 📊 Results  
- Achieved a competitive score on the Kaggle leaderboard with a well-optimized TensorFlow DNN model.  
- Gained insights into the impact of feature engineering and neural network architecture on prediction accuracy.
