# 🚀 Spaceship Titanic - Kaggle Competition  

![Spaceship Titanic](https://storage.googleapis.com/kaggle-competitions/kaggle/31265/logos/header.png)  

## 📖 Overview  
This project was part of the **Kaggle Spaceship Titanic Competition**, where the goal was to predict whether passengers aboard the fictional Spaceship Titanic were transported to another dimension. Using machine learning, I developed predictive models to achieve competitive results.  

## ✨ Features  
- **Data Preprocessing:**  
  - Handled missing data using imputation techniques.  
  - Performed feature engineering to create meaningful insights.  
- **Exploratory Data Analysis (EDA):**  
  - Visualized data trends and relationships.  
  - Uncovered patterns that influenced predictions.  
- **Model Development:**  
  - Trained and optimized various machine learning models, including:  
    - Random Forest  
    - Gradient Boosting (XGBoost, LightGBM)  
    - Logistic Regression  
  - Utilized hyperparameter tuning (GridSearchCV, RandomizedSearchCV) to improve performance.  
- **Model Evaluation:**  
  - Evaluated models using metrics like accuracy, precision, recall, and F1-score.  

## 🛠️ Tools & Technologies  
- **Programming Language:** Python 🐍  
- **Libraries & Frameworks:**  
  - Pandas  
  - NumPy  
  - Scikit-learn  
  - Tensorflow
  - Matplotlib, Seaborn  
- **Development Environment:** Jupyter Notebooks  

## 📊 Results  
- Achieved a competitive score on the Kaggle leaderboard.  
- Improved model performance through iterative experimentation and feature optimization.
